# BIMSASU

Revit 2024 ~ 2027용 무료 플러그인 · by [nosasu](https://nosasu.com) — 사수 없는 사람 모여!

**[최신 버전 다운로드](https://github.com/kklidi/BIMSASU-release/releases/latest)** · [소개 페이지](https://kklidi.github.io/BIMSASU-release/)

## 설치

1. Revit을 모두 종료합니다.
2. [Releases](https://github.com/kklidi/BIMSASU-release/releases/latest)에서 `BIMSASU-Setup-<버전>.exe`를 받아 실행합니다. (관리자 권한 필요 없음)
3. Revit을 실행하고 "게시자를 확인할 수 없습니다" 창이 나오면 **[항상 로드]**를 누릅니다.

새 버전이 나오면 Revit을 시작할 때 알려 드립니다. (리본 **About BIMSASU**에서 끌 수 있음)

## 주요 기능

| 패널 | 기능 |
|---|---|
| 도면 | A1toA3 Scale, MultiCopy, Export Schedule |
| 문자 | Text List (프로젝트 전체 문자 목록·찾아 바꾸기·엑셀), Text Edit (선택 문자 일괄 수정) |
| 검토 | DEF Markup (DEF_ 주석을 인쇄·PDF·DWG에서 자동 제외), Revision Manager |
| 모델 | Find CAD, Ceiling Height |
| 보기 | Tab Color (파일별 뷰 탭 색 구분) |
