# BIMSASU

Revit 2024 ~ 2027용 무료 플러그인 · by [nosasu](https://nosasu.com) — 사수 없는 사람 모여!

**다운로드: [kklidi.github.io/BIMSASU-release](https://kklidi.github.io/BIMSASU-release/)** · 설치 파일은 [Releases](https://github.com/kklidi/BIMSASU-release/releases/latest)

## 설치

1. Revit을 모두 종료합니다.
2. `BIMSASU-Setup-<버전>.exe`를 실행하고 라이선스에 동의한 뒤 Revit 버전을 고릅니다. 관리자 권한은 필요 없습니다.
3. Revit을 켜고 "게시자를 확인할 수 없습니다" 창이 나오면 **[항상 로드]**를 누릅니다. Revit 버전마다 한 번씩 묻습니다.

수동 설치: `BIMSASU-<버전>.zip`을 풀어 `Revit20XX` 폴더 안의 내용을 `%AppData%\Autodesk\Revit\Addins\20XX`에 복사합니다.

제거: Windows 설정 → 앱 → BIMSASU. 자세한 내용은 [데이터와 개인정보 안내](DATA-PRIVACY.md)의 "지우는 법".

## 업데이트

새 버전이 나오면 BIMSASU가 알려 주고, 기본 설정에서는 Revit을 모두 닫을 때 설치합니다. 리본의 **About BIMSASU**에서 자동으로 설치 / 알림만 / 알리지 않음을 고를 수 있습니다.
