최신 버전 받기

최신 버전 확인 중… · Windows · 관리자 권한 필요 없음
설치 전에 Revit을 모두 종료하세요. 처음 실행할 때 "게시자를 확인할 수 없습니다" 창이 나오면 [항상 로드]를 누르세요.

주요 기능

  • DEF Markup — DEF_ 주석을 인쇄·PDF·DWG에서 자동으로 제외
  • Text List / Text Edit — 프로젝트의 모든 문자를 표로 보고, 찾아 바꾸고, 엑셀로 내보내기
  • Tab Color — 열린 파일마다 뷰 탭 색 구분
  • MultiCopy, A1toA3 Scale, Export Schedule, Revision Manager, Find CAD, Ceiling Height

라이선스

  • 무료이며, 개인과 회사(상업적 업무 포함) 모두 사용할 수 있습니다.
  • 향후 버전에서 일부 기능이 유료로 바뀔 수 있습니다. 이미 설치한 버전은 계속 사용할 수 있습니다.
  • 오픈소스가 아니며 수정·재판매·리버스 엔지니어링은 할 수 없습니다.
