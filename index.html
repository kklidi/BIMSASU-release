최신 버전 확인 중… · Windows · 관리자 권한 필요 없음
설치 전에 Revit을 모두 종료하세요. 설치 화면에서 Revit 버전(2024~2027)을 고릅니다. 수동 설치용 ZIP도 같은 곳에 있습니다.
처음 실행할 때 "게시자를 확인할 수 없습니다" 창이 나오면 [항상 로드]를 누르세요. Revit 버전마다 한 번씩 묻습니다.
Revit 2027에서 이 창이 뜬 채로 Revit이 꺼지는 경우가 있습니다. 다시 실행해 [항상 로드]를 누르면 다음부터는 묻지 않습니다.

주요 기능 (리본 BIMSASU 탭, 22개)

  • 도면 — Grid to Crop 그리드·레벨 끝을 자르기 영역에 맞추고 치수 안내선·자동 치수 · Multi Copy 여러 뷰 한 번에 복제 · Batch Rename 뷰·시트 이름을 규칙으로 한 번에 · Sheet Sync 엑셀 도면목록으로 시트 만들기·고치기 · A1toA3 Scale 시트에 A1·A3 축척 함께 적기 · Excel Table 엑셀 표(병합·테두리)를 도면에 · Schedule Colors 일람표 칸을 규칙대로 색칠 · Export Schedule 일람표를 엑셀로
  • 문자 — Text List 모든 문자를 표로 보고 찾아 바꾸기·엑셀 · Text Edit 고른 문자 일괄 수정 · Font Replace 글꼴 일괄 교체(굴림 → 맑은 고딕)
  • 검토 — Submit Check 제출 전 점검을 한 창에서(축척 표기·임시 문구·덮어쓴 치수·빠진 태그·리비전 구름 등) · DEF Markup DEF_ 주석을 인쇄·PDF·DWG에서 자동 제외 · Revision Manager 리비전 구름 목록·엑셀 · Revision Colors 리비전 차수별 구름 색
  • 모델 — Room Number 룸 번호를 누르는 순서·위치 순서대로 다시 매기기 · Room Tag Relink '?'가 된 룸 태그 다시 연결 · Ceiling Height 천장고를 재서 룸에 입력 · Model Cleanup 안 쓰는 뷰·템플릿·필터·패밀리 정리 · Find CAD 링크·삽입 CAD 찾기
  • 보기 — Why Hidden 요소가 왜 안 보이는지 진단하고 바로 고치기 · Tab Color 파일마다 뷰 탭 색 구분

한 번에 바꾼 것은 Ctrl+Z 한 번으로 되돌아갑니다. 바뀐 점은 릴리스 노트에 있습니다.
